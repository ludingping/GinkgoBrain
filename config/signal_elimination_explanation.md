# 信号筛选日志指标解释

> 本文档对应 `signal_elimination_log.md`（TC-A7 实验），解释其中各项筛选指标的含义及背后的设计逻辑。

---

## 一、整体流程概述

信号筛选（Signal Elimination）是特征工程的最后一道关口。其目标是在将信号送入强化学习环境之前，自动剔除**无效信号**和**冗余信号**，只保留对模型真正有价值的特征。

筛选分两步执行，依次判定：

```
Step 1: Sharpe 门控 → 剔除反向收益信号
Step 2: 相关性门控 → 剔除冗余重复信号
```

---

## 二、核心指标详解

### 2.1 Sharpe（夏普比率门控）

**公式：**
$$\text{Sharpe} = \frac{\mu_r}{\sigma_r}$$

其中 $\mu_r$ 为该信号在历史回测中策略收益的均值，$\sigma_r$ 为收益的标准差。

**本次阈值：** `< -0.2`（Sharpe 低于 -0.2 的信号被淘汰）

**含义：**

| Sharpe 值 | 信号解读 |
|-----------|---------|
| `> 0` | 信号正向有效，跟随该信号能获得正期望收益 |
| `0 ～ -0.2` | 信号较弱但未达淘汰线，勉强保留 |
| `< -0.2` | 信号**反向有害**，跟随该信号会系统性亏损，必须剔除 |

**实例：**
- `sig_mom_stoch_state` 的 Sharpe 为 `-0.594`，远低于 `-0.2`，说明该随机指标信号长期指引方向错误，被直接淘汰。
- `sig_trend_macd_hist` 的 Sharpe 为 `-0.167`，虽为负值但未超过阈值，得以保留（模型仍可学习其弱信号）。

---

### 2.2 Correlation（相关性门控）

**公式：**  皮尔逊相关系数（Pearson ρ）

$$\rho = \frac{\text{Cov}(X, Y)}{\sigma_X \cdot \sigma_Y}, \quad \rho \in [-1, +1]$$

**本次阈值：** `|ρ| > 0.95`（两信号绝对相关性超过 0.95 则认为高度冗余）

**含义：**

高相关信号对模型没有额外信息增量。若两个信号 $A$ 和 $B$ 相关性 $|\rho| > 0.95$：
- 只保留 Sharpe 更高的那个（信息质量更好）
- 剔除 Sharpe 较低的那个（冗余）

这样做防止观测空间被重复特征占据，避免模型过度关注同一维度的信息，减少维度诅咒。

**实例：**

| 被淘汰信号 | 保留信号 | ρ | 原因 |
|-----------|---------|---|------|
| `sig_trend_price_above_ma` (Sharpe +0.528) | `sig_mom_rsi_trend` (Sharpe +0.693) | +0.982 | 两者高度正相关，保留 Sharpe 更高的 RSI 趋势信号 |
| `sig_trend_ema_cross` (Sharpe +0.682) | `sig_trend_slope_21` (Sharpe +0.745) | +0.978 | 两者高度正相关，保留 Sharpe 更高的斜率信号 |
| `sig_mom_rsi_zone` (Sharpe +0.093) | `sig_mom_rsi_trend` (Sharpe +0.693) | -0.952 | 两者高度**负**相关，信息相同方向相反，保留质量更高的 |

> **注意**：负相关（如 ρ = -0.952）同样属于冗余，因为模型只需其中一个信号即可得到全部信息（只是方向反转），保留两者没有额外收益。

---

### 2.3 State-only（状态专用信号豁免）

部分信号标注为 `*(state-only)*`，这类信号被**豁免** Sharpe 门控：

```yaml
state-only 信号列表:
  - sig_regime_drawdown    # 市场回撤状态
  - sig_vol_atr_pct        # ATR 波动率百分比
  - sig_vol_bb_position    # 布林带位置
  - sig_vol_bb_width       # 布林带宽度
```

**豁免原因：**

这些信号并不直接驱动买卖决策，而是描述**市场当前所处的状态和风险环境**，提供模型理解"现在处于什么样的市况"的上下文。即使其单独与收益的 Sharpe 较低，它们对模型的状态感知也不可或缺，因此不参与 Sharpe 淘汰，仅参与相关性淘汰（防止重复状态描述）。

## 四、筛选逻辑流程图

```
所有候选信号
     │
     ▼
[Sharpe 门控]
  是否属于 state-only？
  ├─ 是 → 跳过 Sharpe 检查 → 进入相关性检查
  └─ 否 → Sharpe < -0.2？
           ├─ 是 → ❌ 淘汰（反向有害）
           └─ 否 → 进入相关性检查
     │
     ▼
[相关性门控]
  存在已保留信号 S，使 |ρ(当前, S)| > 0.95？
  ├─ 是 → 比较两者 Sharpe
  │        ├─ 当前更高 → 保留当前，淘汰 S
  │        └─ S 更高   → ❌ 淘汰当前
  └─ 否 → ✅ 保留
```

## 五、对模型训练的影响

1. **减少观测维度**：从候选信号池淘汰 4 个冗余/有害信号，使观测空间更紧凑，有助于 PPO 的 Policy 网络收敛。

2. **提升信号质量**：剔除 Sharpe 为负的信号（如 `sig_mom_stoch_state`），避免模型学到系统性反向交易的错误模式。

3. **消除多重共线性**：高相关信号会导致梯度更新在相似方向上重复叠加，破坏训练稳定性。筛除后特征更独立，策略梯度估计更准确。

4. **保留状态感知能力**：state-only 信号的豁免机制确保模型始终能感知市场波动和回撤状态，有助于学习风险管理行为（配合 `risk_aversion_coef` 奖励塑形）。
