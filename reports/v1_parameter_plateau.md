## 4. 结论

1. **趋势 gate（SMA200）是结构**：参数平台宽、跨资产成立。保留为底座。
2. **SMA50 清仓退出不是被证明的结构**：BTC 上依赖回撤的形态（慢跌有效、震荡有害、急跌无效），pre_val 平台只有两档，跨资产不成立。定性从"新底座候选"降为"BTC 专属、待实盘 A/B 观察的候选"。此前 pre_val 那次"确认"的 0.68 本身就没过 2/3，只是同方向。
3. 降回撤的下一个候选应换成对回撤形态不敏感的机制：**波动率目标仓位**（vol targeting），它不依赖退出时机，跨资产证据充分，且不需要预测。
4. 流程修订：§1.1 验收增加两条前置——参数邻域（±20%）内结果同向，至少一个兄弟资产上方向一致；不满足的规则最多进 A/B，不进底座。
